Cómo usar la API

Envía tu clave en cada solicitud como encabezado. Las respuestas son JSON.

curl https://app.easylistings.website/api/v1/contacts \
  -H "Authorization: Bearer el_live_..." \
  -H "Content-Type: application/json" \
  -d '{"email":"comprador@example.com","name":"Ana Pérez","phone":"+18095550100","tags":["zapier"],"addToPipeline":true}'
